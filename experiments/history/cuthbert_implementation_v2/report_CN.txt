Cuthbert：实现审查和修改
2026-10-29

结论
现有 IF2、DMOP 和 IFAD 扩展确实使用了 Cuthbert 的原始 PF 更新及重采样接口，核心结构符合 Ed/Giles 在会议中提出的方向。本轮保留这部分实现，修复了公共接口在 JIT 下检查扰动向量时的实际错误，并补充直接调用公共接口的验证和说明。

这是本地实现审查及验证完成，不是维护者已经接受接口，也不是新的参数估计比较。接下来可以审阅本目录的调用说明和补丁，再讨论是否需要调整接口；无需先重跑历史 Dacca 实验。

会议要求如何落实

1. 使用目标包的 PF 和接口（15:20:40—15:21:40、15:27:20）。
   IF2 和 DMOP 都调用 particle_filter.build_filter；每个月的重采样、状态传播、观测权重和归一化常数更新由原 filter_combine 执行。原 particle_filter.py、filtering.py、systematic.py 和 multinomial.py 未修改。
   我们新增的 scan_final 调用原 filter_prepare/filter_combine，只返回最后一步状态，并可对每步使用 jax.checkpoint。它是新增的时间循环，不能说整个高层 cuthbert.filter 都被直接调用；也不能把它说成重新编写了 PF 更新。

2. IF2 的参数扰动可供不同模型使用（15:28:06—15:28:52）。
   model_factory(parameters) 返回原 build_filter 所需的三个模型函数。iterated_filtering.fit 在通用模块中包装这些函数，使每个粒子携带状态和参数，加入初始及逐观测区间的参数扰动，并让状态与参数按相同祖先索引重采样。
   每轮末再次用原重采样函数得到等权参数集合，整组参数进入下一轮；没有每轮只保留均值再重新生成参数集合。均值用于返回估计值和记录。
   模型仍需提供参数变换、状态模拟和观测密度。用户无需为每个模型重新编写扰动与 IF2 循环。支持范围是当前接口规定的 bootstrap PF，不能称为支持 Cuthbert 的所有模型和滤波器。

3. 从原 ADPF 机制增加折扣（15:28:22—15:28:42）。
   原 stop_gradient_decorator 保留。新增 discounted_stop_gradient_decorator 同样调用原重采样函数，在输出 log 权重中加入 alpha * (selected - stop_gradient(selected))。
   该项前向数值为零；alpha 控制继承的权重导数。状态传播中的路径导数仍保留。alpha=1 与原 ADPF 的相应梯度机制对照，alpha<1 则使用折扣导数。
   本接口要求每个观测时刻重采样，且梯度阶段需要可重参数化的状态模拟。不能直接套到自适应重采样、guided proposal 或需要离散过程 score 修正的模型。

4. 提供可读的必要修改（15:29:17—15:29:59）。
   full.patch 是相对固定上游 c737efe3098b2b5ecaa7d8b976e7cea246998b17 的完整补丁；changes_this_round.patch 只显示相对上一版本本地扩展的改动。
   file_changes.json 分开记录算法、支持代码、测试、文档和打包设置；行数包含注释和文档字符串，不代表“最少算法行数”。本轮没有因为文件名称或形式不同而重写已经复用原包的算法。

本轮实际修改

运行代码：_estimation.broadcast_tree 原先判断输入 v 是否是 JAX Tracer，再尝试 bool(jnp.all(valid))。当扰动向量在 JIT 函数外创建并被函数引用时，v 可能是具体数组，但校验结果已经被追踪，因而触发 TracerBoolConversionError。
现在先计算 all_valid，再判断 all_valid 是否是 Tracer。普通无效输入继续抛出 ValueError；JIT 下的无效尺度继续产生明确失败状态。扰动公式、PF 更新、折扣公式和优化器算法未改变。

测试：增加正常和负扰动尺度两种捕获数组输入的回归用例。修改前两例均复现错误；修改后正常输入完成两阶段，无效输入不更新参数、不进入后续评分。

文档和示例：说明原包函数与新增包装之间的关系。示例先用同一模型调用原 PF/ADPF，对照 alpha=1，再调用公开的 ifad.fit。为 dmop.log_likelihood 补充返回类型，消除该函数的文档类型警告。

通用接口与历史 Dacca 驱动的关系

通用 iterated_filtering.fit 每轮采用 cooling_rate**m，轮内尺度固定；dmop.fit 接收 init/update 优化器接口，最小化负 log likelihood；ifad.fit 组合两阶段并用原 Cuthbert PF 独立评分。

早期 J1024、180 秒实验的 kernels.if2_step 和 gradient_step 按单步暴露参数集合及优化器状态，让运行程序按时间停止、保存和继续。它们使用原 PF、原 ADPF 或 dmop.log_likelihood，但没有通过一个公共 fit 完成整个实验。

论文 J5000 实验的 cuthbert_mif 采用论文的轮内冷却 a**((iteration+month/T)/50)，初始扰动仅用于 IVP；cuthbert_train 使用 PyPOMP Adam、每坐标学习率和 -loglik/600，与论文设置对齐。其训练循环也没有调用通用 dmop.fit。

这些差异有具体的实验用途。统一成一个函数需要额外设计冷却、停止、恢复和优化器接口；会议没有把这种重构规定为必要条件，本轮没有强行合并。历史实验仍只证明历史驱动的行为；下面的新检查证明公共接口能接入 Dacca，不声称已用公共接口重现历史完整拟合。

验证结果和范围

- 119 项选定测试通过：31 项扩展测试（含本轮新增的 2 项）、88 项原有回归测试。60 项未选择；这不是全部上游测试通过。
- 执行 entangled 生成的 IFAD 示例，1 项通过、9 项未选择。示例比较同一模型的原 ADPF 与 alpha=1，并真实执行 ifad.fit。
- 原始 Dacca：600 个月、每月 20 Euler 步、23 个自由参数；CPU、J32，1 轮 IF2、1 次梯度更新、2 次独立评分。模型和数据与冻结文件逐字节一致。验证 alpha=0/.97/1 前向值与原 PF 一致、alpha=1 梯度与原 ADPF 在预定容差内一致、零扰动 IF2 与正确配对过程随机数的原 PF 一致、组合 API 与分别调用两阶段的最终参数完全一致。
- Dacca 比较预定 rtol=1e-5、atol=1e-4；alpha=1 梯度最大绝对差为 0.00091552734375，满足包含相对误差项的逐元素判据，不能称为梯度逐位相等。
- Dacca 这次接入检查使用很小的学习率及显式梯度裁剪，只检查接口和组合行为。没有评估拟合效果或评分精度，不能替代 J1024/J5000 结果，也不能用其耗时宣称算法加速。
- Ruff、ty、代码示例生成和文档构建通过。格式检查限于 7 个手写 Python 文件；生成示例通过 lint、类型检查和实际执行。pytest 的 5 个 xdist_group 标记警告来自已有测试；文档剩余 4 个链接警告来自未修改的 factorial_football 示例。
- 完整补丁在干净上游副本上实际应用，并核对所有修改文件的 SHA；上一版本的 17 个文件仍与旧 manifest 一致。详细记录见 review_manifest.json。

需要保留的数值限制

同一 Dacca 终点和相同评分 keys 下，将参数作为 JIT 输入得到 [-3811.871826171875, -3823.09423828125]；将参数捕获为编译常量的另一份原 PF 调用得到 [-3800.257568359375, -3828.514404296875]，最大差 11.6142578125。
公共 IFAD 的评分与参数作为输入的原 PF 逐项相同。这项差异也出现在两种原 PF 调用之间；当前记录表明 float32、长时间滤波在不同编译方式下不能保证同一随机数产生逐位相同的结果。这里没有完成其数值原因的专项分析，不把它归因于某个已证实的编译器机制，也不据此宣称算法正确性或跨编译完全一致。
旧验证失败日志和比较脚本保留在 validation_history；没有修改模型、拟合算法或放宽数值容差来隐藏差异。零扰动比较还修正过一次参照随机数的配对：IF2 即使尺度为零，也将传播 key 分为扰动和过程两个 subkey，因此参照 PF 必须使用过程 subkey。
