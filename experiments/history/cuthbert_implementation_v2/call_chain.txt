Cuthbert 函数调用及代码来源
固定上游：c737efe3098b2b5ecaa7d8b976e7cea246998b17
“新增”指相对这个上游版本；不表示这些函数已经是 Cuthbert 正式发布的功能。

普通 PF（上游已有）
模型 init_sample / propagate_sample / log_potential
  -> particle_filter.build_filter
  -> Filter.init_prepare / filter_prepare / filter_combine
  -> 原 resampling_fn、vmap(propagate_sample)、观测 log 权重、log_normalizing_constant
上游 cuthbert.filter 驱动时间循环并返回各时间点状态。

ADPF（上游已有）
原 systematic.resampling 或 multinomial.resampling
  -> 原 autodiff.stop_gradient_decorator
  -> 原 particle_filter.build_filter
  -> 对 PF log likelihood 使用 JAX 自动微分
该机制提供梯度设施，不等于包自带了本实验的 Adam 参数估计流程。

IF2（我们新增）
iterated_filtering.fit
  -> 初始参数复制成完整参数粒子集合
  -> 每轮：初始参数扰动；模型初始状态生成
  -> 包装原模型传播函数：先扰动该粒子参数，再按新参数传播状态
  -> 包装原观测函数：使用该粒子当前参数计算观测密度
  -> 原 particle_filter.build_filter
  -> 新 scan_final 调用原 filter_prepare / filter_combine
  -> 原 resampling_fn 对末端状态和参数共同重采样
  -> 整组等权参数传入下一轮，按轮降低扰动尺度

DMOP（我们新增）
原 resampling_fn
  -> 新 discounted_stop_gradient_decorator
       先按 stop_gradient(logits) 调用原 resampling_fn
       加 alpha*(selected-stop_gradient(selected)) 到输出 log 权重
  -> 原 particle_filter.build_filter
  -> 新 scan_final 调用原 filter_prepare / filter_combine
  -> dmop.log_likelihood
  -> dmop.fit 中的 jax.value_and_grad
  -> 调用用户提供的 optimizer.init / optimizer.update
  -> 保存参数、目标值、梯度范数和成功/失败记录

IFAD（我们新增）
ifad.fit
  -> 分出三个随机流
  -> iterated_filtering.fit
  -> dmop.fit（IF2 失败则跳过）
  -> 原 particle_filter.build_filter + 普通重采样，固定终点独立评分
  -> 返回两阶段记录、每次评分和 log(mean likelihood)
本公共 API 的评分来自 Cuthbert PF；历史正式比较的统一最终评分来自原始 PyPOMP PF。不能混淆这两件事。

文件及用途
原 particle_filter.py                 原 PF 构造和更新，未修改
原 filtering.py                      原高层时间循环，未修改
原 systematic.py / multinomial.py     原重采样实现，未修改
autodiff.py                          保留原 ADPF 函数；新增一个折扣装饰器
iterated_filtering.py                 通用参数扰动包装、IF2 轮次、完整参数集合传递
dmop.py                              折扣 PF 调用和梯度优化循环
ifad.py                              组合两阶段和独立评分
_estimation.py                       参数/输入检查、PyTree 工具、扰动、只返回终态的时间循环
tests/.../test_parameter_estimation.py 公式、原方法对照、PyTree/JIT/vmap、失败、冻结坐标和组合 API 检查
docs/...                             调用说明和实际执行公共 API 的例子
