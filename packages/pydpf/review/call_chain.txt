PyDPF 实际调用与扩展边界
基线 a7487ce1c344c70e1a244e75725b950deb15e146，版本 1.2.3。

原有 PF
FilteringModel
  prior_model.sample / dynamic_model.sample / observation_model.fitness（或 score）
  -> ParticleFilter._make_PF_prior / _make_PF_proposal
  -> ParticleFilter._register_functions 中的 initial_sampler / pf_sampler
  -> 原 SystematicResampler 或 MultinomialResampler
  -> 原 normalise
  -> 原 SIS.forward 的逐时刻循环
  -> 原 LogLikelihoodFactors 输出每期 likelihood

原有 ADPF
StopGradientDPF
  -> 原重采样函数
  -> StopGradientResampler.forward
       原输出 log 权重加上选中权重的 stop-gradient 修正
  -> 上述同一个 ParticleFilter/SIS
  -> Torch 自动微分
Torch Adam 是外部优化器。原包教程没有提供统一训练循环。

新增梯度折扣
StopGradientDPF(alpha=...)
  -> StopGradientResampler(base_resampler, alpha=...)
  -> 同一个原重采样函数、相同前向修正
  -> alpha<1 时缩放继承的 log 权重导数
alpha 参数是本地候选补丁增加的，不能把这一调用称为固定上游原本已有的 API。

新增通用 IF2
IteratedFiltering.forward
  -> 每轮保留完整参数集合；加入初始扰动
  -> 用 Prior / Dynamic / Observation 包装用户的正常模型函数
       Prior：过程扰动后调用原模型 prior.sample，连接状态和参数
       Dynamic：对随祖先选出的参数做扰动，再调用原模型 dynamic.sample
       Observation：用粒子的参数构造模型，调用其原 fitness/score
  -> 原 FilteringModel
  -> 原 ParticleFilter 和 SIS.forward 完成整轮滤波
  -> 末端调用原重采样函数，使参数集合等权
  -> 完整参数集合进入下一轮；均值仅作估计值和记录

IFAD 示例
新 IteratedFiltering -> torch.nn.Parameter(warm.parameters)
  -> 原教程式的 torch.optim.Adam 循环
  -> 修改后的 StopGradientDPF(alpha=.97)
  -> 固定终点、新随机流下的普通 PF 评分
没有把这段外部训练循环包装成 PyDPF 原生 MLE，也没有增加另一个通用 fit 函数。

保持未变的原有计算
SIS 类、ParticleFilter 类、SystematicResampler 类、MultinomialResampler 类，
FilteringModel、normalise、batched_select、LogLikelihoodFactors 和所有分布代码。
review_manifest.json 记录原类源文本的逐字节核验及所有修改文件 SHA。

模型适配
新增 IF2 不含 Dacca 状态数或参数名，但模型 factory 必须支持每个粒子不同的参数。
不自动处理任意 nn.Parameter 模型、guided proposals、任意状态结构或实验作业恢复。

具体函数位置与文件 SHA 见 function_locations.json 和 review_manifest.json。
