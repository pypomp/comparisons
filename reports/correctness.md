# Correctness

These checks compare the original package code with our changes. Results below include the records collected through 1 November 2026. Pending jobs are listed in the dated [status](status.md).

The [comparison with existing Kevin/Aaron code](reference_tests_20261101.md) reports the actual test formulas and recalculation: 23/24 saved pairs satisfy the CuTe formula, with one J5000 exception. These are retrospective diagnostics, not Dacca-specific acceptance thresholds.

The [review of the gradient tests](gradient_tests_20261101.md) distinguishes an implementation discrepancy from GPU repeatability and from mathematical correctness. The original Dacca thresholds were not calibrated against repeated GPU calculations. Their failures remain recorded; they alone do not establish an implementation defect. The user accepts forward-PF agreement for proceeding with the empirical comparison while derivative agreement is disclosed separately.

The original TFP snapshot of 324 pairs remains archived. The completed run has 515 pairs: 370 normal exits, 127 test/collection failures, eight no-test exits, nine timeouts and one abort per side. Original/candidate outcomes and failed-test identities match in every pair. This does not imply that all tests passed. [Completed-run details](validation_20261101.md).

The Cuthbert v3 change calls the unchanged original alpha=1 resampling correction and defaults to `checkpoint=False`. Disabling checkpointing passed the recorded CPU checks, but did not make all GPU gradients agree at the planned Dacca starts. The three earlier failed tests also failed in unchanged upstream in a separate A40 diagnosis; that result does not explain the new gradient differences. A new diagnostic control compares the original and modified code repeatedly, including a wrapper that uses the full original `cuthbert.filter` time loop. This control has not replaced production code. The [completed repeated-gradient diagnosis](cuthbert_repeats_20261101.md) saved all 54 evaluations: all corresponding forward values are identical, while seven of nine unchanged-original self pairs at J=5000 fail the earlier gradient rule. This directly shows why that rule is insufficient as a standalone stop condition.

The [new PyDPF startup review and TFP full-Dacca check](pydpf_startup_and_tfp_20261101.md) keep the failed exact Adam-state comparison separate from formal fitting. The new PyDPF regression uses deterministic operations only in its test process, with exact assertions retained; production execution is unchanged. TFP has a new full-scale GPU check in progress, with CPU preflight evidence explicitly separated.

The [completed TFP full-Dacca check](tfp_full_Dacca_20261101.md) has 72 exactly matching forward endpoint pairs, nine finite filter/gradient calls, three finite IF2 passes and four finite Adam proposals. Its original cost split failed; the original failed record is retained. A new shared-prefix allocation fits the unchanged forecast within the same total budget. The [particles final review](particles_20261101/report.md) includes source restoration and independent recomputation of all saved fitting/scoring records; no numerical experiment was rerun.
